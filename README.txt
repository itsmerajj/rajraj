Drop your images in this "images" folder using these exact filenames
(or edit the src="" paths in index.html to match whatever you name them):

  profile.jpg          -> your headshot, used in the About section
  courseflow.jpg        -> PRJ/01 thumbnail
  dining-trends.jpg     -> PRJ/02 thumbnail
  studybuddy.jpg        -> PRJ/03 thumbnail
  gitpad.jpg            -> PRJ/04 thumbnail
  office-hours.jpg      -> PRJ/05 thumbnail
  bus-predictor.jpg     -> PRJ/06 thumbnail

Tips:
- Any image format works (.jpg, .png, .webp) - just update the file extension in index.html to match.
- Project thumbnails look best as screenshots or mockups around 800x500px (16:10 ratio) - they'll be cropped to fit either way.
- Profile photo should be roughly square - it's cropped into a circle automatically.
- If a file is missing, the browser just shows a small broken-image icon, so make sure filenames match exactly (case-sensitive on some systems).
